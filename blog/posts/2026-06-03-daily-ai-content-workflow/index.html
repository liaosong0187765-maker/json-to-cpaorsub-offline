每日 AI 内容抓取到博客发布的最小闭环

这是一篇测试文章，用来固定 `/blog/` 的文章页结构。后续真实文章可以由 Markdown 生成，保持同样的导航、目录、正文排版和底部 CTA。

目标不是每天复制一堆链接，而是把值得留下的资料加工成可读、可查、可复用的个人博客文章。最小闭环先从静态 HTML 开始，等发布链路稳定后，再逐步加入自动抓取和 Markdown 转换脚本。

推荐原则：抓取可以自动化，判断和表达要保留自己的观点。公开发布时只引用必要片段、来源链接和自己的总结，不全文搬运别人的文章。

目录结构

博客使用独立目录，不影响当前主页工具：

  • `blog/index.html`：博客首页和文章列表。
  • `blog/assets/blog.css`：博客独立样式。
  • `blog/posts/yyyy-mm-dd-title/index.html`：每篇文章一个静态目录。
  • `blog/content/`：后续可存放 Markdown 草稿和抓取来源。

每日流程

  1. 抓取 RSS、网页、论文、工具更新或你手动收藏的链接。
  2. 筛选出真正值得写的内容，记录来源链接和判断理由。
  3. 写成 Markdown：标题、摘要、关键点、自己的判断、引用来源。
  4. 用固定模板转成 HTML，输出到 `blog/posts/`。
  5. 更新 `blog/index.html` 的文章列表。
  6. `git add blog`，commit，push，等待 Cloudflare Pages 发布。

发布到网站

当前站点已经可以通过 Cloudflare Pages 发布。以后只要把新文章放进 `blog/` 并推送到 GitHub，线上路径就是：

`https://mars-y.com/blog/posts/2026-06-03-daily-ai-content-workflow/`

下一步

等这个模板确认后，可以继续加三个脚本：`fetch_content.py` 抓取内容，`markdown_to_blog_html.py` 生成文章页，`build_blog_index.py` 更新首页列表。

模板已可复用

后续新增文章时复制这个目录，替换标题、日期、摘要和正文即可。自动化脚本也可以直接以这个 HTML 结构作为输出模板。
